# Browser Support Matrix

This document defines the targets verified across desktop, tablet, and mobile browsers.

---

## 1. Primary Desktop Browsers
*   **Google Chrome:** Latest 2 versions.
*   **Apple Safari:** Latest 2 versions.
*   **Mozilla Firefox:** Latest 2 versions.
*   **Microsoft Edge:** Latest 2 versions.

## 2. Mobile Browsers
*   **Chrome for Android:** Responsive grid layouts verified.
*   **Safari on iOS (iPhone/iPad):** Glassmorphism layout blur styles checked.

## 3. Polyfill Standards
We target ES6+ specifications. CSS Variables and Backdrop Blur filters must fail-safe on older systems.
