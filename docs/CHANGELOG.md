## [1.0.0-alpha] - 2026-07-17

### Added
*   Decoupled Unified Content Registry container.
*   Zod validation schemas for experiences, projects, blogs, publications, and resources.
*   Next.js 15 metadata, structured JSON-LD, Sitemap, RSS feeds, and robots.txt.
*   Client search overlays, command palettes, and AskMahesh floating widget.
*   Reusable `PageShell` layouts and `MDXComponents` typographic replacements.
*   Global prefers-reduced-motion configuration.
*   Framer Motion slide entrance page transitions and scaled spring dialogs.
