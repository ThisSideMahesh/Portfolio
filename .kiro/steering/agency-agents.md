# Agency Agents Integration

This project has access to specialized AI agents from the [Agency Agents](https://github.com/msitarzewski/agency-agents) collection. Each agent has deep expertise in their domain with unique personality, workflows, and deliverables.

## Installed Location

All agents are available at: `~/.kiro/skills/agency-agents/`

## Key Agents for Portfolio Development

### Design Division (`~/.kiro/skills/agency-agents/design/`)
- **UI Designer** (`design-ui-designer.md`) - Visual design, component libraries, design systems
- **UX Researcher** (`design-ux-researcher.md`) - User testing, behavior analysis
- **UX Architect** (`design-ux-architect.md`) - Technical architecture, CSS systems
- **Visual Storyteller** (`design-visual-storyteller.md`) - Visual narratives, multimedia content
- **Whimsy Injector** (`design-whimsy-injector.md`) - Personality, delight, playful interactions

### Engineering Division (`~/.kiro/skills/agency-agents/engineering/`)
- **Frontend Developer** (`engineering-frontend-developer.md`) - React/Vue/Angular, UI implementation
- **Senior Developer** (`engineering-senior-developer.md`) - Complex implementations, architecture
- **Rapid Prototyper** (`engineering-rapid-prototyper.md`) - Fast POC development, MVPs
- **Technical Writer** (`engineering-technical-writer.md`) - Developer docs, API reference
- **Code Reviewer** (`engineering-code-reviewer.md`) - Constructive code review, quality gates

### Marketing Division (`~/.kiro/skills/agency-agents/marketing/`)
- **Content Creator** (`marketing-content-creator.md`) - Multi-platform content, copywriting
- **SEO Specialist** (`marketing-seo-specialist.md`) - Technical SEO, content strategy
- **Social Media Strategist** (`marketing-social-media-strategist.md`) - Cross-platform campaigns

### Product Division (`~/.kiro/skills/agency-agents/product/`)
- **Product Manager** (`product-manager.md`) - Full lifecycle product ownership
- **Feedback Synthesizer** (`product-feedback-synthesizer.md`) - User insights, priorities

### Testing Division (`~/.kiro/skills/agency-agents/testing/`)
- **Accessibility Auditor** (`testing-accessibility-auditor.md`) - WCAG compliance, a11y testing
- **Performance Benchmarker** (`testing-performance-benchmarker.md`) - Load testing, optimization

## How to Use

### Option 1: Reference an Agent
```
"Hey Kiro, act like the Frontend Developer agent from agency-agents and help me build a React component"
```

### Option 2: Read Agent File
```
"Read the UI Designer agent file from ~/.kiro/skills/agency-agents/design/design-ui-designer.md and use that personality"
```

### Option 3: Invoke Specific Agent for Task
```
"Using the UX Researcher agent's methodology, help me plan user testing for the portfolio"
```
